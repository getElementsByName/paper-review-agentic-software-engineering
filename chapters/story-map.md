# 발표 Story Map

<KeyMessage message="발표 흐름: 문제 인식 -> 구조 이해 -> 한계와 실증 -> 후속 탐색 확장" />

```mermaid
flowchart TB
  subgraph four [요약]
    A[문제 인식]
    B[구조 이해]
    C[한계·실증]
    D[탐색 확장]
  end
  subgraph seven [상세]
    S1[1. Why Now]
    S2[2. 현장 신호]
    S3[3. 연구 신호]
    S4[4. SASE 구조]
    S5[5. 한계·실증]
    S6[6. 탐색 가이드]
    S7[7. 마무리]
  end
  A --> S1
  A --> S2
  A --> S3
  B --> S4
  C --> S5
  D --> S6
  D --> S7
```

1. Why Now: 왜 지금 이 주제가 중요해졌나
2. 현장 신호: No Vibes Allowed
3. 연구 신호: 논문 문제 인식과 SASE
4. SASE(Structured Agentic Software Engineering) 핵심 구조
5. 한계·리스크와 실증 설계
6. 탐색 가이드: 키워드·읽기 경로·교육·역할 전환
7. 마무리: 쟁점 언어 · 결론
