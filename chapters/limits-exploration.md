# 탐색 성숙도 프레임: 6단계

<KeyMessage message="이해 단계의 깊이를 점검하는 읽기 도구; L2 키워드 정렬에서 시작해 L3 구조 이해로 간다." />

| 단계 | 탐색 상태 | 핵심 확인 개념 |
|---|---|---|
| L1 | 용어 노출 | ASE, Agentic Coding, SE 3.0 |
| L2 | 키워드 정렬 | Evidence, Merge-readiness, Artifact-centric |
| L3 | 구조 이해 | BriefingScript, MentorScript, LoopScript |
| L4 | 쟁점 비교 | 속도 vs 신뢰, 자동화 vs 책임성 |
| L5 | 교차 검증 | 논문 주장과 실무 사례의 정합성 확인 |
| L6 | 자기 언어화 | 우리 맥락의 용어집과 질문집 정리 |

- 권장 시작점: L2 → L3
